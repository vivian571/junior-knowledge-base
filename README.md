# 自家版初中知识库（项目）

建立：2026-11-03，Vivian 拍板立项。挂靠目标：初中知识库与玩中学游戏（goal-2）。
公开仓库：https://github.com/vivian571/junior-knowledge-base （2026-11-03 建立，后续慢慢改）
定位：这是 Vivian 与孩子共建学习项目的**数据底座**。先有知识库，再在其上做创作（游戏层等，借鉴 cn-math-taxonomy 的玩法），顺序不可颠倒。

## 结构

- `data/nodes.json` — 节点（唯一数据源）。字段照 cn-math-taxonomy 的逻辑：id、subject、name、loc（版本落点）、type、level、status、source、definition、mastery、diagnostic、root_note、tier、part_of。
- `data/edges.json` — 先修边。`from` 是先修，`to` 是后继；strength 分硬（概念依赖，错了可回溯）／软（教学顺序）。
- `kb.py` — 查询脚本：`stats` 统计、`list [科目]`、`show <id>`、`back <id>` 回溯链、`search <关键词>`。
- `intake/` — 投喂原件存档（学案、错题、练习册照片的转录与原件引用）。
- `CHANGELOG.md` — 每次添加／修改的修订记录，只追加。
- 轮次报告（重点总结、差异清单）在 `~/workspace/goals/goal-2/files/`，是给人看的报告；**数据以本项目的 json 为准**，两边不一致时改报告从数据。

## 编号规则

- 数学（青岛版）：`qd-m7a-*`（章组 A/G、章内节点三位数字、跨册先修 P）
- 英语（外研版）：`wy-e7a-*`（S Starter、G 语法、P 语音、U〈单元〉细化）
- 语文（统编版）：`tb-c7a-*`（R 阅读、W 写作、A 古诗文篇目、P 跨册先修）

## 状态流转

- `骨架`：只有结构，没内容（目录自采）。
- `待校准`：自采了通用内容（定义、标准、诊断题），未与手里的课本／学案核对。
- `已入库`：内容来自 Vivian 投喂的真实材料（学案、错题、练习册），或已经她验收校准。
- 校准只能由真实材料触发：她抽查对上、或投喂进来对上，才转 `已入库`；对不上按材料改，并记 CHANGELOG。

## 投喂协议（长期有效）

Vivian 投喂练习册、错题、不会的题、老师划的重点等材料后，Muse 的处理固定为四步：
1. 原件（或转录）存 `intake/`，注明日期与来源；
2. 对照现有节点：能落进已有节点的，补进该节点（错题落 root_note 与 diagnostic，眼见的真实错因优先于自建回溯注）；落不进的，新建节点并连先修边；
3. 有冲突以投喂材料为准，改数据，旧结论在 CHANGELOG 里留痕，不静默覆盖；
4. 回报一行：这次动了哪些节点（新增／修改／校准各几个）。

规则归属：知识库的结构与内容口径由 Vivian 与孩子定，游戏层规则归孩子改；Muse 只做添加、修改与记账，不代他们定规则。
